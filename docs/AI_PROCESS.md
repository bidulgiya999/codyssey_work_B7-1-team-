# C 담당 — 사전 기획·이론 검색·대본 처리

담당: 황승재. 서비스는 코디세이의 Anthropic 호환 Claude 연결을 사용한다. 사용자가 말한 ‘지피티가 자연스럽게 묻는 흐름’은 대화형 AI의 사전 기획 기능으로 구현한다. 공급자 설정은 [AI_SETUP.md](AI_SETUP.md)를 따른다.

## 처리 순서

- message: 사용자 발언에서 명시된 조건만 추출한다. 저장한 Brief와 최근 성공 Q/A 최대 5쌍을 함께 제공한다. 모르는 조건은 추측으로 확정하지 않는다.
- briefing: 부족한 주제·목적·타겟 세그먼트·연령·길이·등장 방식·인물·연출·핵심 메시지를 한 번에 최대 두 개 질문한다.
- ready: 조건 요약을 반환하고 사용자 확인을 기다린다. 모델이 confirmed=true를 임의 지정할 수 없다.
- generate: 완성된 조건으로 제작 템플릿 두 후보를 고르고 관련 자료 최대 세 개를 제공한다. 템플릿은 시연·공감 상황극·설명·관찰 중심의 팀 작법 제안이다. 3막 구조를 모든 릴스에 강제하지 않는다.
- drafted/revise: 기존 조건·최신 대본과 수정 요청으로 새 버전을 만든다. 장면 번호와 정수 초 구간이 목표 길이 전체를 빈틈·겹침 없이 덮어야 한다.

## 근거와 연구 질문

reference_cards는 출처·허용 범위·한계가 검토된 개념 카드다. 모델은 이번에 검색된 card_id만 인용한다. research_agenda의 8개 항목과 structure_options는 연구 질문/제작 제안이며 학술 출처로 인용할 수 없다. 영상 품질·몰입·조회수 효과를 실측했다고 말하지 않는다.

현재 자료 연결은 키워드·한국어/영문 별칭을 활용한 검색이다. 원문 PDF 전체를 모델 가중치에 학습시키거나 강의자료 업로드/OCR을 자동화하지 않았다. 팀이 새 자료를 검토하면 source/card와 페이지·이용 조건을 추가한다.

## 오류와 저장

키는 브라우저에 전달하지 않는다. HTTP timeout 90초, 전체 처리 제한 105초를 둔다. timeout·권한·한도·잘림·잘못된 JSON·출처/시간 검증 실패를 사용자에게 구분 안내한다. 자동 공급자 우회나 무제한 재시도는 하지 않는다.

B가 사용자·대화방·version/처리 잠금을 검증하고, AI 호출 전에 쓰기 트랜잭션을 끝낸다. C의 검증 결과를 B가 저장한 다음 응답한다. 실패하면 기존 성공 기획·대본·버전을 유지하고 실패 원인을 기록한다.
