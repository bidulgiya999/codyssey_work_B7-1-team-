# 비교 대상과 재작성 이력

아이디어·초기 실행 환경을 살펴본 비교 대상은 [L-jy16/ai_chatbot](https://github.com/L-jy16/ai_chatbot)이다. 원본 저장소의 코드·README·배포 주소·팀 실적을 현재 팀의 결과물로 제시하지 않는다.

## 사실에 맞는 변경 이력

- 2026-10-19 초기 폴더를 만들 때 원본 develop의 e7b34807e384e802851f916332340b2f311b2941을 가져왔다. 초기 인증·계정 기반에는 원본과 동일한 파일이 있었다.
- 이후 인스타 릴스 사전 기획·대본 버전·자료 검색·장면 검증·화면을 새로 구성했다. 이 단계까지도 ‘모든 코드가 처음부터 독립 작성’이었다고 말하지 않는다.
- 2026-10-21 사용자의 재구현 요청으로 계정 입력 규격·계정 서비스·인증 라우터·비밀번호 저장·세션 식별·DB 연결·계정 모델·브라우저 계정 연동을 새 구조로 작성했다. 자원 API와 AI 채팅 API의 담당 경계도 분리했다.
- 현재 제품은 인스타 릴스 제작 코치다. 경제/뉴스 검색·실시간 트렌드 분석·원본 시나리오·원본 UI/README를 실행 코드로 사용하지 않는다. 원본의 배포 URL은 우리 서비스 URL이 아니다.

## 유지하는 호환성과 비교 한계

기존 로컬 사용자의 계정·대화를 지우지 않기 위해 users와 reels_* 물리 테이블 이름, 기존 ID·질문/응답·버전을 유지한다. 새 비밀번호는 버전이 있는 scrypt로 저장하고 기존 bcrypt는 성공한 로그인에서만 갱신한다. 이 호환성은 원본의 기능·문구를 복제하기 위한 것이 아니다.

scripts/audit_reference.py는 로컬의 비교 커밋과 현재 소스를 읽기 전용으로 대조한다. 비어 있지 않은 동일 파일과 주석/문서 문자열을 제외한 전체 Python AST 일치를 확인한다. 파일 단위 비교는 공유된 코드 조각이 전혀 없거나, 독립 저작·라이선스·표절 여부가 증명됐다는 뜻은 아니다. FastAPI·SQLAlchemy의 공통 사용법과 과제 필수 인증 기능은 공통일 수 있다.

Git 과거 이력과 이 문서를 없애 독립 작성인 것처럼 보이게 하지 않는다. 이전 팀의 커밋을 현재 A 이송하·B 김시현·C 황승재의 실적으로 옮겨 기록하지 않는다. 현재 팀의 기여는 실제 작성·검토·PR 기록으로 남긴다.
