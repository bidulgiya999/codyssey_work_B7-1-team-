2026-10-19 원본 소스와 Git 메타데이터를 새 작업 폴더에 복사했다. 바탕화면 원본 폴더는 수정하지 않았다. 인증·DB 기반을 참고하고 전체 실행 경로·화면·API·자료·문서를 릴스 대본 코치로 전환했다. 기본 실행 파일은 app.main:app이고 AI 제공자는 Groq다.

기존 저자의 작업을 현재 팀의 개인별 기여로 바꾸지 않는다. 과거 주제의 코드·화면·문서·PDF·도표는 현재 작업 트리에서 제거했고 원본 Git 이력에서 확인할 수 있다. 이 서비스의 구현 명세는 현재 README와 docs 문서다.

현재 호스트의 Git HTTPS 전송이 네트워크 오류로 동작하지 않아 새 원격 저장소는 GitHub API로 파일 스냅샷을 가져오는 방식으로 초기화한다. 원본의 전체 커밋 그래프는 로컬의 upstream 참조와 원본 저장소에 보존한다. 새 원격의 가져오기 커밋은 원본 팀원들의 커밋 이력을 복제한 것이 아니다. 이후 원격 main/develop/feature 브랜치와 로컬 참조를 맞춰 일반 협업을 이어갈 수 있게 한다.
