# 실제 연결된 공개 이론 자료

2026-10-19 기준 **공개 원문 12종의 검토한 절을 한국어 개념 카드 21개로 연결**했다. 자료 후보는 김미림 교수님 관련 보류 자료 3종을 포함해 15종이다. 원문 전체를 학습한 모델이 아니라, 로컬 카드에서 관련 내용을 검색해 코디세이 요청에 제공하는 방식이다. 한 요청에 최대 3개를 제공한다.

## 실제 요청 흐름

현재 질문의 한국어·영어 이론 별칭을 우선 검색하고, 기존 기획은 보조 맥락으로 사용한다. 검색 카드의 원문 요약·팀 적용 제안·한계를 구분해서 코디세이에 전달한다. 모델이 반환한 card_ids는 실제 검색된 최대 3개 안에서만 허용한다. 설명에 출처가 없으면 확인 불가 안내로 바꾸고, 대본 생성은 기존 장면별 근거 검증을 유지한다.

답변 화면과 저장된 대화 응답에 저자·원문 링크·관련 절·PDF 링크·확인한 PDF 쪽수·라이선스·적용 한계가 남는다. PDF 쪽수는 **파일 첫 페이지를 1로 세는 PDF 기준**이며 책의 인쇄 쪽수와 구분한다. 웹 절만 확인한 자료는 PDF 쪽수를 비워둔다. PDF가 웹 도구에서 열렸다는 것과 파일을 로컬에 확보했다는 것은 구분한다. 로컬 DNS 제한으로 원본 PDF 바이트를 받지 못했으므로 원본 파일·SHA-256은 보관했다고 주장하지 않는다. 서비스 실행 중 원문 사이트에 접속하지 않으며, 검토한 한국어 카드는 저장소에 있다.

```powershell
.\.venv\Scripts\python.exe scripts/check_knowledge.py --query '프라이타크와 3막'
.\.venv\Scripts\python.exe scripts/check_knowledge.py --query '서스펜스'
.\.venv\Scripts\python.exe scripts/check_knowledge.py --query '인지 부하' --scope commercial
```

API 키 없이 검색·페이지·출처를 확인할 수 있다. 실제 코디세이의 자유로운 문장 품질은 키 설정 후 별도로 점검한다. 김미림 교수님 자료는 원문 재사용 조건이 확인되지 않아 검색에서 제외한다. 이번에 찾은 자료를 교수님의 저작이나 추천 자료로 표시하지 않는다.
